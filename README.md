# 사이 — 거리 측정 웹앱

Nominatim으로 실제 장소를 검색하고, OSRM으로 자동차 도로 거리를 계산합니다. 직선 거리도 지원합니다. 결과 하단의 **지도에서 보기**는 선택한 두 좌표가 입력된 OpenStreetMap 길찾기를 새 탭에서 엽니다. 직선 거리 모드에서도 지도 링크는 자동차 경로를 표시합니다.

## 로컬 실행

Node.js 22 이상에서 `npm run dev`를 실행하고 http://localhost:3000 에 접속하세요. Windows PowerShell에서 npm 실행 정책 오류가 발생하면 `npm.cmd run dev`를 사용하세요. 파일을 직접 더블클릭하지 말고 HTTP 서버로 실행하세요.

외부 npm 패키지, API 키, Redis, 데이터베이스, 환경변수, 빌드 과정이 필요 없습니다. `npm run check`로 JavaScript 구문을 검사할 수 있습니다.

## GitHub → Vercel 배포

1. 이 폴더의 파일을 GitHub 저장소에 업로드합니다.
2. Vercel에서 Add New → Project → 해당 저장소를 Import합니다.
3. Framework Preset은 **Other**, Root Directory는 이 파일들이 있는 폴더를 선택합니다.
4. Build Command는 비워 두세요. `vercel.json`에서 빌드를 비활성화하고 출력 폴더를 현재 폴더로 지정했습니다.
5. 환경변수 없이 **Deploy**를 누릅니다.

## 사용 방법

출발지와 도착지를 각각 입력한 뒤 **검색**을 누르고 결과에서 정확한 장소를 선택하세요. 측정 방식을 고르고 **거리 계산하기**를 누르면 총거리가 나옵니다. 입력을 수정하거나 측정 방식을 바꾸면 기존 결과는 지워집니다. 검색 결과는 브라우저에 최대 24시간 캐시합니다.

## 공개 지도 API의 이용 조건과 한계

**Nominatim 공개 API는 소규모 이용을 위한 서비스입니다. 앱 운영자는 [공식 이용 정책](https://operations.osmfoundation.org/policies/nominatim/)을 준수해야 합니다. 앱 전체 최대 초당 1회이며, 자동완성·대량 조회가 금지됩니다.** 이 앱은 명시적 검색만 수행하고, 같은 브라우저에서 1.1초 간격으로 요청하며 Web Locks 지원 시 같은 출처의 여러 탭도 직렬화합니다. 검색 결과와 마지막 요청 시각을 localStorage에 보관하며 저장소를 사용할 수 없으면 메모리 캐시로 동작합니다. 배포한 웹사이트의 Referer가 서비스 식별에 사용됩니다.

**Redis나 공유 서버 상태가 없는 정적 앱이므로 여러 사용자·기기의 합산 요청을 초당 1회로 보장하지 못합니다.** 이 구성으로 불특정 다수에게 대규모 서비스를 제공하면 정책을 준수할 수 없습니다. 소수 사용자로 시작하고 전체 트래픽이 정책을 넘기 전에 별도 제공업체 또는 자체 Nominatim 및 전역 요청 제한 장치로 전환해야 합니다. `config.json`에 검색·경로 URL이 분리되어 있어 프런트엔드 코드 변경 없이 호환 제공업체로 교체할 수 있습니다. 다른 제공업체의 인증 키가 필요한 경우 브라우저에 비밀 키를 넣지 마세요.

검색어는 Nominatim으로, 자동차 거리 계산 시 좌표는 OSRM으로 전송됩니다. 검색어와 결과는 해당 브라우저에 저장되며 브라우저 사이트 데이터를 삭제하면 제거됩니다. 민감한 정보는 입력하지 마세요. 외부 Google Fonts 요청이 발생하며 글꼴 로드 실패 시 시스템 글꼴로 표시됩니다.

Nominatim은 장소 검색 서비스이며 경로 거리를 제공하지 않습니다. 도로 거리는 [OSRM route API](https://project-osrm.org/docs/v5.24.0/api/#route-service)의 추천 자동차 경로 기준으로 최단 거리나 실시간 교통을 보장하지 않습니다. 공개 OSRM 서버는 가용성 보장이 없으며 한국을 포함해 OSM 지도 데이터가 부족한 지역에서는 장소 검색이나 경로 탐색이 실패할 수 있습니다. 실패 시 직선 거리 측정을 선택할 수 있습니다. 직선 거리는 지구를 구로 근사한 Haversine 공식(평균 반지름 6,371,008.8m)으로 계산합니다.

지도 배경은 설명용 일러스트이며 실제 경로는 **지도에서 보기**에서 확인하세요. 데이터 저작권: © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), ODbL.
